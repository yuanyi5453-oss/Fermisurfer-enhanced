# 发布验证

本次从公开发布目录独立构建，应用源码与已安装增强版逐文件 SHA256 一致。
环境：Ubuntu 22.04 / WSLg，wxWidgets 3.0.5，现有 gcc/g++、OpenGL/GLU 和 zlib。
只调整发布构建脚本的头文件搜索路径，使其使用随附 GL2PS 头文件，不依赖系统开发包。

使用仓库内合成三能带输入进行验证，不使用任何个人材料计算数据。

| 检查 | 结果 |
| --- | --- |
| 独立构建 | 通过；保留上游 nesting.cpp 的两个字符串常量警告 |
| 三维旋转数学、非零胞体中心、长方形二维投影比例 | 通过 |
| wx 按钮绑定、90°/180°往返、复位、三维状态不变 | 通过 |
| PNG/SVG 导出、OpenGL 状态恢复、错误参数和覆盖保护 | 通过 |
| 方形顺90°、逆90°、180°对照直接像素转置 | 三项平均通道误差均为0 |
| 长方形顺90°与转置图共同区域 | 平均通道误差0 |
| Reset image 对照原图 | 像素完全一致 |
| SVG 同色填充几何双向采样距离 | 最大约0.0003741 pt；阈值0.01 pt；无嵌入位图 |

GL2PS 的 BSP 排序可能将同一个填充区域重新剖分，因此不能要求旋转前后顶点集合逐一相等。
SVG 检查按颜色比较三角形填充区域，双向采样顶点、边中点及质心；不是对所有连续点的严格等价证明。
PNG 则直接比较完整像素数组，允许不同驱动的微小边缘光栅化差异。

WSL 当前缺少可选 numpy/Pillow，因此脚本正确报告跳过额外像素检查；
随后用现有 Windows Python 环境执行同一检查脚本，以上项目均通过，未安装新依赖。
本次未单独重做 PDF 视觉回归，也未声称所有 GPU、macOS、Windows 原生构建或全部特殊显示组合通过测试。
